# A. V. Omkar ? Portfolio

A single-page static portfolio built with HTML, CSS, and JavaScript. `index.html` is the complete site; keep `styles.css`, `script.js`, and the `images` folder alongside it when deploying.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. In **Settings ? Pages**, select the `main` branch and `/ (root)`.
3. Add your domain in the Pages settings and configure DNS using the current GitHub instructions.

## Publish with GoDaddy Web Hosting

Upload `index.html`, `styles.css`, `script.js`, and the complete `images` folder to the hosting account website root. A domain registration alone does not include file hosting.
